# 0.1.7-rc.2 安装说明

> **每个版本目录各带一份安装说明**；壳里那份已移除 —— 与更新有关的东西统一放这里。

## 这一版是什么

| 项 | 值 |
|---|---|
| 上游版本 | `@deepseek-ai/dsh@0.1.7-rc.2` |
| 目标平台 | openharmony-arm64（HarmonyOS 设备） |
| 改造内容 | 见 [CHANGES.md](CHANGES.md)：11 个整文件替换 + 图片后端（jimp）+ 2 个 OHOS 原生包 + 顶层 `bin/` |
| 产物 | `dsh-ohos-0.1.7-rc.2.zip`（约 65 MiB，顶层目录必须是 `dsh-0.1.7-rc.2`） |

## 出包

```sh
# 仓库根；--out 指向壳的 rawfile/pkg/（壳构建时会自动这样调）
node scripts/build-dsh.mjs 0.1.7-rc.2 --out <壳>/entry/src/main/resources/rawfile/pkg/dsh-ohos-0.1.7-rc.2.zip
```

壳侧一条命令即可（dsh 输入没变会自动跳过，约 12 秒编完壳）：

```sh
sh <壳>/scripts/build-hap.sh
```

## 验证

```sh
sh <壳>/scripts/check-dsh-runtime.sh    # 只读自检：跑的是哪份包 / 改造点在不在 / 图片后端能不能真跑
```

## 交给别的 agent 时附这几句

```
壳在 <壳仓库路径>，dsh 侧在本仓库（0.1.7-rc.2/）。
规则：不要重启用户正在用的实例（端口 32100）；验证一律起临时实例（换端口 + 独立 DSH_HOME）。
目标：<换版本 / 或只改某一处>。
```
